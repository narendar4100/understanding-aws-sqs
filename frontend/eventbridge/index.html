Amazon EventBridge

Route the event by its content, then let a queue do the waiting

A producer puts an event once. Rules match it and send it to targets. Use EventBridge when the path depends on the event, a SaaS application is the source, or you need archive and replay.

A rule is a route, not a backlog

The default bus receives many AWS service events. A custom bus isolates an application. A rule can have several targets, but a consumer that can be down for an hour should be an SQS target. Archive and replay answers a question SNS and SQS do not answer alone: show me those events again.

Fragile design

Every consumer is a Lambda target

  • • A slow function drops work when it throttles.
  • • Email is expected from a bus that has no email subscriber.
  • • Nothing was archived, so yesterday cannot be replayed.

Exam-ready design

Rules select the work. SQS owns the wait.

  • • High-value orders match a numeric filter and land on a fraud queue.
  • • Every order matches a second rule whose target is SNS.
  • • All matching rules run. The first match does not stop the others.

What EventBridge will not do for you

  • • It does not store a consumer backlog. Target a queue for that.
  • • It does not provide SQS visibility timeout or maxReceiveCount.
  • • A standard rule does not poll SQS or Kinesis. Pipes is the polling feature.
  • • It does not send email or SMS by itself. Target SNS for a person.
  • • Delivery is at least once. Consumers must be idempotent.

Custom events are the main EventBridge bill

Example: 10 million Northline orders are 10 million custom events. Routing one event to three SQS queues does not turn it into three EventBridge publishes, but it does create three queue deliveries. Many AWS service events on the default bus are priced differently. Confirm the current pricing page.

Well-Architected checks

  • • Security: a bus policy controls publishers, and each target uses its own role.
  • • Reliability: SQS targets, DLQs, an archive, and idempotent consumers.
  • • Cost: keep events small and do not invoke an expensive target for every heartbeat.
  • • Operations: store the rule and a sample event with the application so a contract change is tested.

Exam drills

An event must reach email and a durable worker. Which combination fits?

Target SNS for email and SQS for the worker. EventBridge can send to both.

Yesterday's events were archived and processed by a bug. How do you try them again?

Replay that time window after the consumer is fixed and idempotent.

The fraud rule requires amount >= 1000. An order for 999 arrives. Does fraud run?

No. A broader OrderPlaced rule can still match.

A design polls SQS, enriches the message, and calls an API. Which feature is that?

EventBridge Pipes, not a normal bus rule.

Two rules match one event. Does the first stop the second?

No. All matching rules run.
