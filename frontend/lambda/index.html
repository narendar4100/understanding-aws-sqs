Name the invocation model before you tune retries

API Gateway and an Application Load Balancer invoke Lambda synchronously. S3, SNS, and EventBridge invoke it asynchronously, and those calls retry twice. SQS, Kinesis, and DynamoDB streams use an event source mapping: Lambda polls, and the source controls the retry. Reserved concurrency of zero throttles every call.

Fragile design

A long API request and one shared admin role

  • • The browser waits while a report is built.
  • • One busy function consumes the account concurrency pool.
  • • The function joins a private subnet and then cannot reach S3.

Exam-ready design

A short accept path and a buffered worker

  • • The API function validates, stores, publishes, and returns.
  • • The worker has its own role and a reserved concurrency cap.
  • • S3 is reached through a gateway endpoint when the worker is in a VPC.

Best lab: classify the source, then cap the worker

Students classify API Gateway, EventBridge, and SQS. They then calculate reserved concurrency 20 against a burst of 80, and finally set it to 0. A pass includes this sentence: asynchronous Lambda retries twice, while an SQS failure is controlled by visibility timeout and maxReceiveCount.

What Lambda will not do for you

  • • It will not run longer than 15 minutes.
  • • It will not stay warm for every future call unless you pay for provisioned concurrency.
  • • VPC attachment does not add a public IP or internet access.
  • • An SQS event source mapping is not an SNS-style push.
  • • A function must not write new objects into the same S3 prefix that invoked it.

Example: one million short runs are often a small bill. A function that waits 10 minutes, or provisioned concurrency left high overnight, is the expensive design. Retries are extra invocations. Confirm current Lambda pricing.

Well-Architected checks

  • • Security: one execution role per function and no static keys.
  • • Reliability: idempotent handlers, async destinations, and reserved concurrency for critical workers.
  • • Performance: size memory for the CPU need and measure cold starts before buying provisioned concurrency.
  • • Cost: keep functions short and do not leave unused provisioned concurrency running.

Exam drills

The function timeout is 15 minutes, but API Gateway REST fails at 29 seconds. Why?

The REST integration timeout is 29 seconds. The Lambda maximum does not extend the caller's wait.

Reserved concurrency is 0. A test invoke arrives. What happens?

It is throttled. Zero means the function cannot run.

An SQS message fails inside Lambda. Where is the DLQ configured?

On the SQS redrive policy. Do not describe it as the two asynchronous Lambda retries.

A private-subnet function must read S3, and there is no NAT. What do you add?

A gateway VPC endpoint for S3, plus the route and IAM permission.

Object-created invokes Lambda, and the function writes another object to the same prefix. What is the risk?

A recursive loop. Use a different bucket or prefix, and filter out the output.
